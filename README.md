## Building

The HTML is generated, never hand-edited.

```bash
python3 build.py --prod          # home
python3 build-pages.py --prod    # the three notebooks
cd market/hub && python3 build-hub.py
```

`shared.py` holds the stylesheet — one source of truth for the design tokens, imported
by every page. Edit that, not a copy.

`--prod` emits the canonical, Open Graph and social-preview tags. Without it, pages
build with `noindex` so a preview copy can never outrank the real site.

## Notes on what is and isn't shown

The trading hub captures are real, taken during market hours. Rupee figures on the GATI
tab are a labelled paper book, not an account. One thing is redacted, and it isn't about
markets: the broker token's account holder is a real person and their name is covered.

The India grid explorer needs 132 MB of binary layers under `work/india-grid/data/`.
They are generated by a separate Research OS repository and copied in.
